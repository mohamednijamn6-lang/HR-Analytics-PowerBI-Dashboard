HR Analytics Dashboard (Excel & Power BI)
📌 Project Overview
This project is an end-to-end HR Analytics dashboard designed to track employee attrition, demographic details, and salary metrics. The raw data was processed in Excel and visualized using Power BI to provide actionable insights for the HR department.

🛠️ Tools & Technologies Used
Microsoft Excel: Initial data exploration, Pivot Tables, and KPI calculations (Attrition Rate).

Power Query: Data cleaning, formatting, and handling dirty data (e.g., standardizing Gender formats).

Power BI: Data modeling, interactive slicers, and custom dashboard design using Format Painter.

📊 Key Insights & Metrics
Total Employees & Attrition Rate: Tracked the overall active workforce vs. employees who left.

Demographics: Filtered insights based on Gender and Job Roles using interactive slicers.

Department-wise Analysis: Visualized the employee count across various departments (IT, HR, Sales, etc.).

Salary Trends: Calculated and charted the average monthly salary by department.
